Keytray

Keytray is a browser extension for Chrome, Edge, and Brave. Its purpose is to read verification codes from Gmail accounts you connect. One account is free. A one-time purchase unlocks more. For each new code it can fill the page, copy the code, or only show it in the popup.

Mail is read in your browser with the Gmail readonly scope. Email bodies are used to find a code and are not saved. Stored items are the code, sender, subject, and time, kept in this browser only. Codes, tokens, and mail are not sent to a server run for this project.

Adding another Gmail account is a one-time purchase. Checkout and the customer login are ExtensionPay and Stripe. The extension only learns whether that login has paid.

What it does

  • Connect one Gmail account for free, or more after a one-time purchase, and list recent codes in the popup.
  • Check for new codes in the background, or sync on demand.
  • Auto-fill a code field, copy the code, or do nothing, per account.
  • Show a Fill chip on a detected code field when a recent code is stored.

Why it asks for Gmail access

Keytray requests the Gmail readonly scope only to find verification codes in mail you already receive. Message bodies are read in this browser and are not saved. Codes, tokens, and mail are not sent to a server run for this project. The developer does not receive them.

The privacy policy is in this repository at docs/privacy.html.

Google access

Sign-in uses Google OAuth. The extension requests https://www.googleapis.com/auth/gmail.readonly and https://www.googleapis.com/auth/userinfo.email. It does not send, delete, or modify mail. You can disconnect an account in the extension settings and revoke access in your Google Account permissions.

Install

This extension is not published. Install it unpacked from the GitHub repository. Setup steps are in SETUP.md.
